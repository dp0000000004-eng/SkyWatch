# SkyWatch

SkyWatch is a modern weather and environment monitoring web application developed as a college project. The project focuses on delivering a clean, responsive, and user-friendly interface for tracking weather conditions, forecasts, and environmental data in an accessible way.

Project Type: Academic / College Project  
Version: 2.0  
Description: majorproject version2

---

## Overview

SkyWatch is designed to help users monitor real-time weather conditions through an intuitive dashboard. With a modern UI and responsive layout, the application aims to provide quick access to essential weather information such as temperature, humidity, wind speed, and atmospheric conditions.

This project demonstrates practical skills in:
- Front-end web development
- Responsive design
- JavaScript-based interactivity
- UI/UX design
- API integration and data presentation

---

## Features

- Real-time weather information
- Search by city or location
- Daily and forecast-based weather updates
- Clean and modern dashboard interface
- Mobile-friendly responsive design
- Easy-to-read weather cards and statistics
- User-friendly navigation and layout
- Lightweight, fast-loading web experience

## Installation

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/dp0000000004-eng/SkyWatch.git
   ```

2. Navigate to the project folder:
   ```bash
   cd SkyWatch
   ```

3. Open the project in a browser:
   - You can open `index.html` directly, or
   - Run a local server if the project requires JavaScript modules or API requests

Example:
```bash
python -m http.server 8000
```

Then open:
```bash
http://localhost:8000
```
